Principles of Information Systems

Complete 50-Question Exam Reviewer (Chapters 10 - 14)

Chapter 10: Information and Decision Support Systems

1. Which stage of decision making involves developing alternative solutions to the problem?
  • a. Intelligence
  • b. Design
  • c. Choice
  • d. Implementation
Answer: b (Design)
2. An optimization model is used to:
  • a. Find a "good enough" solution
  • b. Find the best solution, usually under constraints
  • c. Use "rules of thumb"
  • d. Handle unstructured data only
Answer: b
3. Which report is produced only when a situation is unusual or requires management action?
  • a. Scheduled report
  • b. Demand report
  • c. Exception report
  • d. Key-indicator report
Answer: c
4. What is the primary purpose of a Financial MIS?
  • a. To design new products
  • b. To provide information about the financial health of the organization
  • c. To manage employee payroll only
  • d. To track factory maintenance
Answer: b
5. A Geographic Information System (GIS) is a DSS that:
  • a. Only works with text-based data
  • b. Includes data about the location of objects and activities
  • c. Is used only for government intelligence
  • d. Replaces the need for management reports
Answer: b
6. Which DSS component is a collection of mathematical models and analytical tools?
  • a. The database
  • b. The model base
  • c. The dialogue manager
  • d. The user interface
Answer: b
7. Ad hoc DSS is used for:
  • a. Repetitive decisions
  • b. One-of-a-kind or infrequent problems
  • c. Daily transaction processing
  • d. Generating monthly payroll
Answer: b
8. In the Delphi approach to decision making:
  • a. Members meet face-to-face and shout ideas
  • b. Experts provide input through several rounds of anonymous surveys
  • c. The CEO makes the final decision alone
  • d. Software selects the best option based on data
Answer: b
9. An Executive Information System (EIS) is designed for:
  • a. Data entry clerks
  • b. Middle managers
  • c. Top-level executives
  • d. System administrators
Answer: c
10. What is the final stage in the problem-solving process?
  • a. Choice
  • b. Monitoring
  • c. Implementation
  • d. Intelligence
Answer: b (Monitoring)

Chapter 11: Knowledge Management and Specialized Systems

11. Knowledge that is documented and stored in a database is called:
  • a. Tacit knowledge
  • b. Explicit knowledge
  • c. Virtual knowledge
  • d. Heuristic knowledge
Answer: b
12. A system that can simulate the functioning of the human brain to find patterns is a:
  • a. Expert system
  • b. Neural network
  • c. Robotics system
  • d. Natural language processor
Answer: b
13. In an expert system, the knowledge base contains:
  • a. Facts and rules
  • b. Only raw data
  • c. Customer addresses
  • d. Programming source code
Answer: a
14. Which AI field is concerned with creating machines that can "see" and "hear"?
  • a. Learning systems
  • b. Robotics
  • c. Perceptive systems
  • d. Genetic algorithms
Answer: c
15. The "Turing Test" is used to determine:
  • a. A computer's processing speed
  • b. If a computer can demonstrate human-like intelligence
  • c. The security of a database
  • d. The speed of a network connection
Answer: b
16. What is a "Knowledge Engineer"?
  • a. A person who builds computer hardware
  • b. A person who extracts expertise from a human expert for an AI system
  • c. A manager of a data center
  • d. A technical support agent
Answer: b
17. Genetic algorithms use which concept to find solutions to complex problems?
  • a. Financial accounting
  • b. Survival of the fittest / Evolution
  • c. Backward chaining
  • d. Transaction logs
Answer: b
18. Informatics is the combination of:
  • a. Math and Geography
  • b. Information technology and a specific discipline like medicine
  • c. Biology and Physics
  • d. Hardware and Software engineering
Answer: b
19. An "Avatar" in a virtual reality context is:
  • a. A virus
  • b. A user's graphical representation
  • c. A type of headset
  • d. A database query language
Answer: b
20. Which system helps knowledge workers create, share, and use information?
  • a. TPS
  • b. KMS (Knowledge Management System)
  • c. CRM
  • d. ERP
Answer: b

Chapter 12: Systems Development: Investigation and Analysis

21. The "Waterfall" model is associated with:
  • a. Rapid Application Development
  • b. The Traditional SDLC
  • c. Agile development
  • d. Prototyping
Answer: b
22. What is the main goal of Systems Investigation?
  • a. To write computer code
  • b. To determine if a problem or opportunity exists and if it's worth pursuing
  • c. To train users on the new system
  • d. To buy new hardware
Answer: b
23. Technical feasibility asks:
  • a. Does the system provide a good ROI?
  • b. Can the hardware and software be developed to meet the need?
  • c. Will the employees use the system?
  • d. Is the system legal?
Answer: b
24. What does "Economic Feasibility" primarily involve?
  • a. Political stability
  • b. Cost-benefit analysis
  • c. Time constraints
  • d. Hardware availability
Answer: b
25. A Data Flow Diagram (DFD) is used during analysis to:
  • a. Show the sequence of programming instructions
  • b. Model how data moves through a system
  • c. Calculate the project budget
  • d. Test for hardware errors
Answer: b
26. Which group is responsible for the technical success of the project?
  • a. Steering committee
  • b. Systems development team
  • c. Stakeholders
  • d. External auditors
Answer: b
27. "Scope Creep" refers to:
  • a. A virus spreading through the system
  • b. Unplanned expansion of project requirements
  • c. The cost of electricity for the server
  • d. Employees leaving the project
Answer: b
28. CASE tools stand for:
  • a. Computer-Aided Software Engineering
  • b. Computer-Analysis Systems Environment
  • c. Centralized Application Security Entry
  • d. Code Access Standard Evaluation
Answer: a
29. What is the output of the Systems Analysis phase?
  • a. The final computer program
  • b. The system requirements report
  • c. The hardware purchase order
  • d. The user training manual
Answer: b
30. Direct observation is a technique used in:
  • a. Systems investigation
  • b. Data collection during analysis
  • c. Programming
  • d. System maintenance
Answer: b

Chapter 13: Systems Development: Design, Implementation, Maintenance, Review

31. Logical design focuses on:
  • a. Specifying the exact hardware model
  • b. Describing the functional requirements without specific hardware
  • c. Writing the actual code
  • d. Hiring the programmers
Answer: b
32. Which conversion strategy involves stopping the old system and immediately starting the new one?
  • a. Parallel start-up
  • b. Direct conversion (Plunge)
  • c. Phase-in
  • d. Pilot start-up
Answer: b
33. Unit testing is:
  • a. Testing the whole system at once
  • b. Testing individual programs or modules
  • c. Testing how well hardware fits in a rack
  • d. Testing the users' knowledge
Answer: b
34. Which maintenance type fixes bugs or errors found after implementation?
  • a. Corrective maintenance
  • b. Adaptive maintenance
  • c. Perfective maintenance
  • d. Preventive maintenance
Answer: a
35. A "Patch" is a:
  • a. Hardware upgrade
  • b. Software fix for a specific problem
  • c. New type of monitor
  • d. User password
Answer: b
36. What is the main purpose of a Post-Implementation Review?
  • a. To punish developers for mistakes
  • b. To evaluate if the system met its goals and objectives
  • c. To delete the old data
  • d. To announce the project to the press
Answer: b
37. "Site Preparation" refers to:
  • a. Preparing the physical location for new hardware
  • b. Designing the website
  • c. Formatting hard drives
  • d. Interviewing users
Answer: a
38. User Acceptance Testing (UAT) is performed by:
  • a. The programmers
  • b. The actual users of the system
  • c. The CEO only
  • d. External hackers
Answer: b
39. Data conversion is the process of:
  • a. Encrypting all files
  • b. Moving data from the old system to the new system
  • c. Deleting old records
  • d. Printing paper reports
Answer: b
40. In a "Pilot" start-up:
  • a. Everyone uses the system at once
  • b. Only one branch or group uses the system first
  • c. Both systems run for 1 year
  • d. No testing is done
Answer: b

Chapter 14: Personal and Social Impact of Information Systems

41. Social engineering involves:
  • a. Writing complex AI algorithms
  • b. Using deception to trick people into giving up confidential info
  • c. Building social media sites
  • d. Upgrading server hardware
Answer: b
42. A "Logic Bomb" is a program that:
  • a. Speeds up the computer
  • b. Executes a malicious function when a specific condition is met
  • c. Helps solve math problems
  • d. Monitors network traffic
Answer: b
43. Ergonomics is the science of:
  • a. Saving energy in data centers
  • b. Designing systems to be comfortable and safe for human use
  • c. Protecting software from piracy
  • d. Speeding up internet connections
Answer: b
44. A "Firewall" is designed to:
  • a. Put out physical fires
  • b. Filter incoming and outgoing network traffic
  • c. Back up data automatically
  • d. Cool down the CPU
Answer: b
45. Phishing is a technique used to:
  • a. Catch fish using sensors
  • b. Steal sensitive info via fraudulent emails/websites
  • c. Improve database search speed
  • d. Connect to a printer
Answer: b
46. The "Digital Divide" refers to:
  • a. The gap between those with access to technology and those without
  • b. The difference between 0 and 1 in binary
  • c. Splitting a hard drive into two partitions
  • d. A type of encryption
Answer: a
47. Software Piracy is:
  • a. Writing open-source software
  • b. The illegal copying or use of software
  • c. Selling software at a discount
  • d. Testing software for bugs
Answer: b
48. Which law regulates how the U.S. government collects and uses personal data?
  • a. The Privacy Act of 1974
  • b. The Sarbanes-Oxley Act
  • c. The Clean Air Act
  • d. The Digital Millennium Copyright Act
Answer: a
49. A "Zombie" computer is one that:
  • a. Has been shut down for years
  • b. Is controlled remotely by a hacker for malicious tasks
  • c. Has no monitor
  • d. Is used for gaming only
Answer: b
50. Libel involves:
  • a. Stealing hardware
  • b. Publishing a written false statement that is damaging to a person's reputation
  • c. Copying music illegally
  • d. Forgetting a password
Answer: b
